# Visual encoding

The canonical visual-style specification is now:

- ipcc_visual_grammar.md
- figure_archetypes.md
- fidelity_checklist.md

Key change from version 0.1: strict IPCC fidelity does not permit silent fallback to generic Matplotlib or cmocean palettes.

General scientific-visualisation advice should only fill gaps where the AR6 WGI source corpus is silent. It must not override semantic scenario colours, official WGI colormaps, typography, or documented uncertainty conventions.
